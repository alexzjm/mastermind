# Mastermind

A browser-based implementation of the classic **Mastermind** code-breaking game built with plain HTML, CSS, and JavaScript.

## How to Play

- Try to guess the 4-digit secret code using the colored icons.
- After each guess, you'll get feedback:
  - **Correct color in the correct position**
  - **Correct color in the wrong position**
- You have up to 10 attempts to crack the code!

## Features

- Interactive UI with icon-based input
- Real-time feedback after each guess
- Win/loss tracking with answer reveal
- Fully playable in the browser — no external frameworks

## Getting Started

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Press **START** and begin guessing!

## Tech Stack

- HTML
- CSS (with Google Fonts)
- Vanilla JavaScript
